## Repository 1

**Repository Name:**  QGIS
**Link:**  https://github.com/qgis/QGIS

### Purpose
What does this project do?
This project helps with spatial data management and other mapping features. It has features that help with creating and hosting beautiful maps that are highly customizable.

### Repository Structure
What folders or files stand out?
The readme, python folder and scripts folder stand out. The readme is well done and has nice grphics/plots. The python and scripts folder lend me to believe it probably works well with python.

### Documentation
How helpful is the README?
Yes! It has a table of contents with links and lots of helpful topics. I would say it could better, it would be nice if there was a more straight forward summary on top.

### Activity
Is the repository actively maintained?
Yes, there are a lot of issues, disscusions and commits happening all the time.

### Key Observation
One thing this project does well.
It presents its abilities and features well.

## Repository 2

**Repository Name:**  awesome-gis
**Link:**  https://github.com/sshuair/awesome-gis

### Purpose
What does this project do?
This project is a collection of geospatial tools and sources that help with geoanalysis, developer tools for mapping, map sites, and more.

### Repository Structure
What folders or files stand out?
The .md file (Geospatial-Start-ups-And-Companies.md) because this repo doesn't have much in it. It is pretty much a place that links cool tools so it doesn't have many actual project files.

### Documentation
How helpful is the README?
Pretty helpful, it gets to the point and tells you exatcly what it is right from the start.

### Activity
Is the repository actively maintained?
Yes, but not as much as the other one. It's last commit was in July and it has 89 contributers.

### Key Observation
One thing this project does well.
Oranizes each type of cool project into a category that makes sense and is easy to find.
