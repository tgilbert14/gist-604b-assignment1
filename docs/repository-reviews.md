## Reflection

In 3–5 sentences, explain what you learned about how open source projects are organized.

Most of them have the same folder structures. They often have things like doc(s), src, scripts, python (when it's used), readme's, and install files depending on the project. They also layout website links for additional information and have release builds when relevant (e.g., QGIS 3.44.15) along the right side. It makes sense that there is a general layout and flow that most projects follow so that many people can work on them together and understand where files typically are.
