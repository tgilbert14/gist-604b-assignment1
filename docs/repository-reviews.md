## Repository 1

**Repository Name:**  QGIS
**Link:**  https://github.com/qgis/QGIS

### Purpose
What does this project do?
This project helps with spatial data management and other mapping features. It has features that help with creating and hosting beautiful maps that are highly customizable.

### Repository Structure
What folders or files stand out?
The readme, python folder and scripts folder stand out. The readme is well done and has nice grphics/plots. The python and scripts folder lend me to believe it probably works well with python.

### Documentation
How helpful is the README?
Very! It has a table of contents with links and lots of helpful topics.

### Activity

Yes, there are a lot of issues, disscusions and commits happening all the time.

### Key Observation

It presents its abilities and features well.
