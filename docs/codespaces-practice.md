## Understanding Git Workflow
Explain in 2–3 sentences the difference between:
- Local workspace (Codespace)
- Remote repository (GitHub.com)
A local workspace like Codespace is a cloned copy of your GitHub repository that contains all the files in the project you’re working on. Changes you make in Codespace stay there until you commit and push them to GitHub, and that’s when the main repository updates.
